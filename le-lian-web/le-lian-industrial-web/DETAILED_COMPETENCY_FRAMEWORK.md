# 樂聯工業股份有限公司 - 詳細職能框架

## 職能細項拆解體系

本文檔基於勞動部 iCAP 職能基準和金屬製造業特性，為樂聯工業的所有職位進行深度職能拆解，每個職位的職能都細化到具體的技能項目，以實現精準的職能缺口分析。

---

## 廠務部門

### 廠務經理
**職位等級**：部門主管 | **部門**：廠務部 | **直接下屬**：廠務副理、設備工程師、廠務助理

#### 核心職能細項

**1. 領導與管理能力**
- 1.1 團隊建設與人員管理（招聘、培訓、績效評估）
- 1.2 目標設定與績效管理（制定部門目標、監控進度）
- 1.3 決策制定與問題解決（分析複雜問題、制定解決方案）
- 1.4 跨部門協調與溝通（與其他部門協作、衝突解決）

**2. 安全管理**
- 2.1 安全政策制定與執行（制定安全規程、確保合規）
- 2.2 安全風險評估（識別危害、評估風險等級）
- 2.3 事故調查與改善（分析事故原因、制定預防措施）
- 2.4 安全培訓與宣導（組織安全培訓、提升員工意識）

**3. 成本控制與預算管理**
- 3.1 預算編制與監控（制定年度預算、控制支出）
- 3.2 成本分析（分析成本構成、識別降低機會）
- 3.3 設備投資評估（評估 ROI、制定採購計畫）
- 3.4 能源管理（監控能耗、優化使用效率）

**4. 設備與廠務管理**
- 4.1 設備維護計畫（制定保養計畫、監控執行）
- 4.2 廠房管理（環境衛生、安全設施維護）
- 4.3 應急預案（制定應急計畫、組織演練）
- 4.4 技術更新與改善（評估新技術、推動改善項目）

**5. 溝通與協調**
- 5.1 向上匯報（定期向上級報告、爭取資源支持）
- 5.2 向下溝通（傳達政策、激勵團隊）
- 5.3 橫向協作（與製造、品質等部門協調）
- 5.4 外部溝通（與供應商、客戶溝通）

- 3.2 維護計畫執行（監督保養工作）

- 5.4 外部溝通（與維修廠商溝通）

### 設備工程師
**職位等級**：專業技術 | **部門**：廠務部 | **上級**：廠務經理/副理

#### 核心職能細項

**1. 機械設備操作與維護**
- 1.1 設備操作規程掌握（了解各類設備操作方法）
- 1.2 日常保養執行（潤滑、清潔、檢查）
- 1.3 故障診斷（識別故障類型、判斷原因）
- 1.4 簡單維修（更換零件、調整參數）

**2. 技術文檔與記錄**
- 2.1 設備手冊理解（閱讀技術文檔、理解規格）
- 2.2 維護記錄填寫（記錄保養內容、故障信息）
- 2.3 技術檔案管理（整理設備資料、建立檔案）
- 2.4 改善建議提出（提出優化建議）

**3. 問題解決與分析**
- 3.1 故障分析能力（分析故障原因、判斷嚴重程度）
- 3.2 應急處理（緊急情況下的臨時解決）
- 3.3 改善方案提出（提出改善方案）
- 3.4 效果評估（評估改善效果）

**4. 安全管理**
- 4.1 設備安全操作（遵守安全規程）
- 4.2 危害識別（識別設備危害）
- 4.3 個人防護（正確使用 PPE）
- 4.4 安全意識提升（參加安全培訓）

**5. 溝通與協調**
- 5.1 向上匯報（報告設備狀況、提出需求）
- 5.2 團隊溝通（與操作人員溝通）
- 5.3 廠商溝通（與維修廠商協調）
- 5.4 知識分享（分享設備知識）

## 職能評估等級說明

### 評估等級（0-5 級）

- **0 級**：完全不具備該職能，無相關知識或經驗
- **1 級**：初級水平，具備基本概念，但實踐經驗不足
- **2 級**：中級水平，具備一定知識和實踐經驗，能獨立完成基本工作
- **3 級**：進階水平，具備深入知識和豐富實踐經驗，能獨立完成複雜工作
- **4 級**：高級水平，具備專業知識和豐富實踐經驗，能指導他人
- **5 級**：專家水平，具備深厚專業知識，能制定標準和創新方案

### 職位要求等級

- **基層執行職位**（技術員、班長、品檢員等）：通常要求 2-3 級
- **中層主管職位**（課長、副課長、組長等）：通常要求 3-4 級
- **部門主管職位**（經理、課長等）：通常要求 4-5 級

## 使用說明

1. **員工自評**：員工根據自己的實際情況，對照職能細項進行自評，選擇相應的等級
2. **上級評估**：上級根據員工的實際表現，進行評估，選擇相應的等級
3. **落差分析**：系統自動計算職位要求等級與員工實際等級的差距
4. **培訓規劃**：根據落差分析結果，制定個性化的培訓計畫
