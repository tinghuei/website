# 會議記錄

資料檔：`work-assistant/data/會議記錄範本.md`（固定格式＋撰寫規則）；輸出到 `work-assistant/meetings/YYYY-MM-DD-〔會議名稱〕.md`

## A. 產出會議記錄

1. 讀 `會議記錄範本.md`。若格式狀態仍是「預設」，先提醒使用者：「目前用的是預設格式，建議貼一份公司現行會議記錄讓我對齊」，然後照預設繼續。
2. 讀 `work-assistant/meetings/` 中**同名會議的上一份記錄**，把「主管指示事項」與決議帶入本次「上次會議決議追蹤」。
3. 讀逐字稿/摘要，依範本的「撰寫規則」整理：
   - 嚴格照範本的標題、順序、欄位；範本沒有的區塊不要自己加
   - 只寫實際出現的內容；不確定處標 `【待確認：…】`
   - 決議/指示一律寫成「負責人＋事項＋期限」
4. 若會議日期、名稱、出席者無法從內容判斷，問使用者，不要猜。
5. 存檔後**同步**：
   - 副總的每一項指示 → 依 `/vp-directives` 登錄到 `副總交辦.md`（來源寫「YYYY/MM/DD 〔會議名稱〕」）
   - 負責人是使用者的事項 → 加到 `工作事項.md`
   - 副總對報告方式、文件的評語 → 記到 `副總觀點.md`
6. 回覆：記錄檔位置、新增的副總交辦（VP 編號）、新增的工作事項（W 編號）、所有 `【待確認】` 清單。

## B. 更新固定格式

使用者貼上公司現行的會議記錄範例時：
1. 反推格式：標題層級、區塊順序、表格欄位、日期寫法、編號方式、用語習慣（如「決議」「指示」「辦理情形」）。
2. 取代 `會議記錄範本.md` 中「---」之間的格式區塊，保留下方「撰寫規則」並依範例補充用語規則。
3. 格式狀態改為「已確認（依 YYYY/MM/DD 範例）」。
4. 把反推出的格式列給使用者確認。
