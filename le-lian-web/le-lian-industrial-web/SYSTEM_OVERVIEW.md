# 樂聯工業 教育訓練管理系統 — 功能說明與 TTQS 效益

---

## 一、系統概述

本系統為樂聯工業股份有限公司專屬建置之「教育訓練數位化管理平台」，涵蓋訓練需求評估、課程規劃與執行、電子化審核流程、職能分析及訓練成效追蹤等完整功能鏈。系統依 **TTQS（訓練品質評核系統）PDCA 循環**設計，並整合 **iCAP 職能基準框架**，協助人資單位達成訓練品質認證要求。

## 三、功能模組說明

### 3-1 員工學習端

| 模組 | 功能說明 |
|------|---------|
| **儀表板** | 個人訓練進度總覽：完成課程數、學習時數、待辦事項、最新公告 |
| **課程庫** | 瀏覽全公司課程目錄、報名選課、觀看 YouTube 教學影片、下載講義 |
| **我的課程** | 個人課表管理：進度追蹤、觀看影片、完成課後問卷（L1滿意度）、參加測驗（L2學習效果） |
| **免費課程** | 整合外部免費資源（YouTube、政府補助課程等），一鍵加入公司課程庫 |
| **成就系統** | 電子修課證書、積點獎勵、學習里程碑紀錄，提升學習動機 |
| **職涯地圖** | 依職能缺口推薦學習路徑，連結課程與職等晉升條件 |
| **AI 訓練顧問** | 以對話方式回答訓練相關問題、推薦課程、解說職能標準 |
| **通知中心** | 課程開課提醒、審核結果通知、證書到期警示 |

### 3-2 職能分析模組

| 功能 | 說明 |
|------|------|
| **iCAP 職能基準對應** | 依「技術員/班長、助理專員/組長、工程師/課長、副理/經理以上」四個職級設定職能標準 |
| **員工自評滑桿** | 員工對「專業技能、溝通協作、領導管理、問題解決、團隊合作、安全意識」六向度評分 |
| **主管評估比對** | 提交後顯示員工自評 vs 主管評估 vs iCAP標準 三方雷達圖 |
| **工作職能書上傳** | 上傳 PDF/DOCX/TXT，AI 辨識職稱等級（含手動修正確認 UI）並自動更新基準值 |
| **落差分析卡片** | 六個職能向度缺口評分、達標/警示/危險色階、自動推薦對應補強課程 |
| **職能缺口測驗** | 依落差最大向度自動出題（每職級 7-8 題），提交後顯示正確解析與得分 |
| **部門輪調適合度** | 計算員工職能與目標部門需求的適配分數，輔助跨部門調動決策 |

### 3-3 實體訓練管理

| 功能 | 說明 |
|------|------|
| **訓練記錄 CRUD** | 建立/編輯/刪除實體課程紀錄，支援照片上傳（base64），存入 localStorage |
| **參訓人員分析** | 交叉比對線上課程報名紀錄，顯示每位學員：出勤、進度、問卷、測驗成績、完課狀態 |
| **例行課程管理** | 建立例行訓練排程（法令/內訓/外訓），照片上傳，草稿→送出→核准→完成四階段流程 |
| **訓練紀錄匯出** | 訓練記錄可匯出 Excel（.xlsx）供主管簽核或送TTQS評核使用 |

### 3-4 費用協議書（CFCMHR37）

| 功能 | 說明 |
|------|------|
| **電子化協議書生成** | 依員工資料自動填入表頭（工號/姓名/到職日/部門/職稱/職等/年資） |
| **中文金額格式** | 費用自動轉換為「萬千百十元整」中文大寫格式 |
| **服務年限計算** | 輸入費用自動建議服務年限，計算訓前+增加=訓後年資 |
| **電子簽名** | 支援滑鼠/觸控手寫簽名（Canvas）或上傳簽名圖片，輸出 base64 PNG |
| **完整六節條款** | 依 CFCMHR37 原件完整呈現六大條款（費用返還辦法、服務年限、違約金等） |
| **簽核欄位** | 員工簽名+身分證+地址+電話、主管欄、人資欄、中華民國年月日 |

### 3-5 審核與雙重簽核

```
訓練申請流程
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ 員工提出  │────▶│ 主管審核  │────▶│ 人資複核  │────▶│ 核准完成  │
│ 訓練申請  │     │(managerApproved)││(hrApproved)│     │ 發電子證書│
└──────────┘     └──────────┘     └──────────┘     └──────────┘
                      │ 退回                │ 退回
                      ▼                    ▼
                 申請退件通知          申請退件通知
```

### 3-6 管理與報表

| 功能 | 說明 |
|------|------|
| **年度訓練計畫** | 全年訓練課程排程、預算規劃、執行進度追蹤，支援 Excel 匯入/匯出 |
| **管理報表** | 訓練完成率、部門訓練時數分佈、Kirkpatrick 四層評估摘要、TTQS 指標達成率 |
| **績效追蹤** | 訓後職能提升數據，連結月/季績效考核系統 |
| **講師名冊** | 內部講師資料管理（資歷、授課科目、授課紀錄、評分），符合 TTQS D3 訓練師資要求 |

## 五、TTQS 指標對應關係

TTQS 評核共 **18 項指標**，分屬五大面向。以下說明本系統如何支援各指標。

### P — 計劃 (Plan)

| TTQS 指標 | 對應系統功能 | 產出文件/佐證 |
|-----------|------------|--------------|
| **P1** 訓練政策明確 | 儀表板首頁訓練方針公告、年度訓練目標設定 | 年度訓練計畫書（可 Excel 匯出）|
| **P2** 訓練需求評估 | 職能落差分析（iCAP 六向度自評＋主管評估）| 員工職能缺口報告 |
| **P3** 訓練目標與事業策略連結 | 職涯地圖對應職等晉升條件；部門輪調適合度分析 | 個人職能發展計畫 |
| **P4** 訓練資源規劃 | 年度計畫預算欄位；講師名冊師資管理 | 年度預算分配表 |

### D — 設計 (Design)

| TTQS 指標 | 對應系統功能 | 產出文件/佐證 |
|-----------|------------|--------------|
| **D1** 課程設計系統化 | 課程庫新增/編輯（標題/說明/分類/講師/時數/通過分數） | 課程設計表 |
| **D2** 訓練方法多元 | 線上影片課程＋實體訓練記錄＋免費外部課程整合 | 多元訓練紀錄 |
| **D3** 訓練師資管理 | 講師名冊（資歷/授課記錄/評分）；內部講師認定 | 講師資格審查表 |
| **D4** 訓練教材管理 | 課程庫附件管理；YouTube 影片 ID 整合 | 教材清冊 |

### D — 執行 (Do)

| TTQS 指標 | 對應系統功能 | 產出文件/佐證 |
|-----------|------------|--------------|
| **Do1** 訓練執行依計畫 | 年度計畫甘特進度追蹤；實體訓練例行課程排程 | 執行進度表 |
| **Do2** 訓練資源運用 | 費用協議書電子化（含電子簽名）；訓練費用記錄 | CFCMHR37 費用協議書 |
| **Do3** 訓練紀錄完整 | 實體訓練照片上傳；參訓人員分析；線上課程出席紀錄 | 訓練紀錄（含相片） |

### R — 檢討 (Review)

| TTQS 指標 | 對應系統功能 | 產出文件/佐證 |
|-----------|------------|--------------|
| **R1** 訓練成效評估 L1 | 課後問卷（滿意度）| 學員滿意度調查表 |
| **R2** 訓練成效評估 L2 | 課後測驗（知識技能）；職能缺口測驗 | 測驗成績單 |
| **R3** 訓練成效評估 L3 | 績效追蹤（訓後職能變化）；主管評估比對 | 行為改變評估表 |
| **R4** 訓練成效評估 L4 | 管理報表（部門生產力/品質指標連結）| 組織成效報告 |
| **R5** 審核程序 | 雙重審核流程（主管 + 人資）；通知中心 | 審核簽核紀錄 |

### A — 改善 (Action)

| TTQS 指標 | 對應系統功能 | 產出文件/佐證 |
|-----------|------------|--------------|
| **A1** 訓練結果回饋改善 | AI 訓練顧問建議；職能缺口測驗結果推薦課程 | 改善行動計畫 |
| **A2** 訓練制度持續優化 | 免費課程一鍵加入課程庫；成就系統激勵機制 | 訓練制度更新記錄 |

## 六、效益說明

### 對 員工 的效益

```
學習動機提升
├── 個人化推薦：依職能缺口自動推薦最相關課程
├── 成就與積點：完課即獲電子證書，累積學習里程碑
├── 職涯透明化：清楚看到升職所需職能缺口及學習路徑
└── 自主學習：免費課程庫整合外部優質資源，24/7 可學習
```

### 對 主管 的效益

```
管理效率提升
├── 雙向評估：自評 vs 主管評估雷達圖，溝通有憑據
├── 輪調決策：職能適合度分數輔助部門輪調客觀判斷
├── 一鍵審核：數位化審核流程，不再紙本追蹤
└── 報表即時：管理報表即時呈現部門訓練完成率
```

### 對 人資 的效益

```
行政效率與法遵保障
├── 文件電子化：CFCMHR37 費用協議自動生成，電子簽名存檔
├── 訓練紀錄完整：實體訓練照片+參訓名冊+簽到表一站管理
├── TTQS 佐證便利：每個功能模組對應 TTQS 指標，評核準備省時 70%
├── 雙重審核合規：主管+人資 hrApproved 流程符合勞動法令要求
└── 講師資格管理：內部講師名冊符合職訓局內訓師資審查要求
```

### 對 公司 的效益

```
組織競爭力提升
├── TTQS 評核準備：系統自動產出 18 項指標所需文件佐證
├── iCAP 對接：職能基準與政府 iCAP 架構對應，利於申請補助
├── 訓練 ROI 可量化：Kirkpatrick L1~L4 評估結果供高階決策
├── 人才留任：費用協議電子化降低訓練投資流失風險
└── 數位轉型：從紙本教育訓練管理轉型為完整數位化平台
```
