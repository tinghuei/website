# 樂聯工業股份有限公司 網站設計規劃

## 公司背景分析

**樂聯工業股份有限公司** 成立於民國75年（1986年），是一家專注於工業製造與相關技術服務的專業公司，主要從事辦公家具相關產品的製造、加工與整合服務。公司由鄭凱仁先生擔任負責人，組織架構完整，涵蓋管理、製造、品保、業務及後勤支援等單位。

### 核心價值與定位
- **品質至上**：確保產品與服務符合客戶期待
- **專業精進**：鼓勵持續學習與技術提升
- **誠信負責**：以誠信為企業經營基礎
- **團隊合作**：重視跨部門協作與共同成長
- **永續經營**：兼顧企業發展、員工成長與社會責任

## 設計理念選項

### <response>
**設計方案一：現代工業極簡風格**

**設計運動**：Industrial Minimalism（工業極簡主義）

**核心原則**：
1. **功能至上**：每個設計元素都有明確的用途，無冗餘裝飾
2. **材質感**：運用深灰、鋼鐵色、暖白等工業色系，呈現製造業的專業感
3. **幾何秩序**：採用網格系統、直線、明確的邊界，體現工業精密性
4. **對比鮮明**：深色背景搭配高對比的白色文字和亮色重點

**色彩哲學**：
- 主色：深灰色（#2C3E50）+ 鋼鐵藍（#34495E）
- 輔色：工業橙（#E67E22）作為CTA和重點
- 背景：深色系（#1A1A1A）或淺灰（#F5F5F5）
- 文字：高對比白色或深灰
- 情感意圖：專業、可信、穩定、高效

**版面範式**：
- 左右分欄設計，左側為視覺重點（產品/數據展示），右側為文字說明
- 非對稱的卡片布局，營造動態感
- 使用大量留白和明確的分割線區隔內容區塊

**簽名元素**：
1. 工業風格的斜線分割符（SVG divider）
2. 數據視覺化圖表（展示成長指標）
3. 產品流程圖（製造→品保→交付）

**互動哲學**：
- 懸停效果：卡片微微上升，陰影加深
- 點擊反饋：按鈕有明確的按壓感
- 滾動動畫：元素從左/右滑入，營造進度感

**動畫指南**：
- 過渡時間：200-300ms（快速、專業）
- 緩動函數：cubic-bezier(0.4, 0, 0.2, 1)（標準工業感）
- 入場動畫：從邊界滑入或淡入，不超過500ms
- 懸停動畫：按鈕和卡片有subtle上升效果

**排版系統**：
- 標題字體：Poppins Bold（現代、幾何感）
- 正文字體：Open Sans Regular（易讀、專業）
- 字級階層：H1 48px / H2 32px / H3 24px / Body 16px
- 行高：1.6（易讀性）

## 選定設計方案

**我選擇方案一：現代工業極簡風格**

這個設計方案最符合樂聯工業的企業定位。工業極簡主義強調功能性、精密性和專業感，完美呼應製造業的核心價值。深灰色和工業橙的配色既現代又專業，能夠建立客戶信任。非對稱的卡片布局和明確的視覺層級將使複雜的訓練計畫內容變得易於理解。

## 網站架構

### 頁面結構
1. **首頁（Home）** - 公司概況、願景使命、核心優勢
2. **公司簡介（About）** - 詳細公司背景、組織結構、發展歷程
3. **業務範疇（Services）** - 產品與服務介紹、應用領域
4. **品質管理（Quality）** - 品質管理體系、認證資訊、改善成果
5. **人才培育（Training）** - 年度訓練計畫、課程展開、預期績效
6. **聯絡我們（Contact）** - 聯絡表單、公司地址、聯絡方式

### 內容組織
- 首頁：hero section + 公司亮點 + 核心優勢 + 訓練計畫預告 + CTA
- 各頁面：標題 + 內容區塊 + 視覺元素 + 導航

## 視覺資產計畫

- **Hero背景**：工業製造場景或現代工廠視覺
- **產品展示**：辦公家具產品圖片
- **團隊/文化**：員工培訓、團隊合作的圖片
- **數據視覺化**：成長指標、訓練成果圖表
- **圖標**：品質、效率、創新、團隊合作等主題圖標
