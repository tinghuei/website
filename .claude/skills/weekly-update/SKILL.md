# 每週工作事項更新

資料檔：`work-assistant/data/工作事項.md`（主檔）、`work-assistant/data/副總交辦.md`、`work-assistant/data/副總觀點.md`

## 步驟

1. **先讀三個資料檔**，掌握現有事項、編號、副總交辦與副總偏好。
2. **解析使用者提供的內容**（文字、清單、截圖、對話都可以），逐條判斷：
   - 對應到既有事項 → 更新狀態、進度、完成日，不要開新編號
   - 新事項 → 取目前最大編號 +1，建立 `W-###`
   - 判斷不出是哪一筆或狀態時，列出來問使用者，不要猜
3. **分類規則**
   - ✅ 已完成：使用者明確說做完/送出/結案
   - 🔄 進行中：已開始但未完成；要寫「進度/卡關點」
   - 📌 待辦：還沒開始；有期限的依期限排序，無期限的放最後
   - 期限已過仍未完成 → 在事項前加 `⏰逾期`
4. **跨週處理**：若「已完成（本週）」裡有上週以前完成的事項，移到「已完成歸檔」對應週次（ISO 週，週一到週日）。
5. **與副總交辦同步**：事項來源是 `VP-###` 的，狀態變更要同步更新 `副總交辦.md` 的進度紀錄。
   使用者提到的內容若是副總新交辦的，依 `/vp-directives` 規則登錄，再於工作事項建立對應 W 編號。
6. **評估「可上報」**：依 `副總觀點.md` 第五節標準給 ⭐/△/－。
7. 更新「最後更新」日期，存檔。

## 回覆使用者

用精簡格式回報：
```
本週更新（YYYY-MM-DD）
✅ 新完成 N 項：W-xxx …
🔄 進行中 N 項（⏰逾期 N 項）
📌 待辦 N 項，最近期限：W-xxx（MM/DD）
⭐ 建議在主管會議報告：W-xxx、W-xxx（理由各一句）
⚠️ 副總曾提醒：…（只列與本次更新事項相關的）
❓ 需要你確認：…
```
最後詢問是否要接著用 `/vp-report` 產生主管會議報告稿。
