# 工作助理 使用說明

在 Claude Code（網頁 claude.ai/code、手機 App 或電腦版）開啟這個 repo，直接用中文跟 Claude 說話即可。
下面的「指令」打不打都可以，Claude 會依你說的內容自動判斷。

## 四個功能

| 你想做的事 | 指令 | 你只要提供 |
|-----------|------|-----------|
| 更新本週工作（已完成／進行中／待辦） | `/weekly-update` | 隨手寫的工作清單、LINE 對話、筆記 |
| 準備主管會議報告 | `/vp-report` | 不用提供，從工作清單自動挑選 |
| 整理會議記錄 | `/meeting-minutes` | 逐字稿或摘要 |
| 登錄／查詢副總交辦 | `/vp-directives` | 副總說了什麼（原話越完整越好） |

另外，**處理任何工作時**，Claude 都會先查副總交辦紀錄，有相關的提醒會放在回覆最前面：

```
📎 副總曾提醒：
- 〔VP-003，10/06〕對外報價單發出前要先給副總看
```

## 資料檔（Claude 自動維護，你也可以手動改）

```
work-assistant/
├── data/
│   ├── 工作事項.md      ← 所有工作，W-001 起編號
│   ├── 副總交辦.md      ← 副總交辦與提醒，VP-001 起編號，結案也不刪
│   ├── 副總觀點.md      ← 副總看文件的角度，會越用越準
│   └── 會議記錄範本.md  ← 會議記錄固定格式
├── meetings/            ← 每次會議記錄
└── reports/             ← 每週主管會議報告
```

## 第一次使用：先做這三件事（越早越準）

1. **貼一份公司現有的會議記錄**，說「這是我們的會議記錄格式」→ Claude 會把格式固定下來。
2. **貼副總以前批改過的文件或退件意見**，說「這是副總的意見」→ Claude 學習副總的審視角度。
3. **把目前手上的工作和副總交辦的事一次列出來** → 建立第一版清單。

## 每週建議流程

1. 週五（或會議前一天）：貼這週做的事 → `/weekly-update`
2. 接著：`/vp-report` → 拿到報告稿，修改後使用
3. 會議後：貼逐字稿 → `/meeting-minutes`，副總的指示會自動進交辦清單
4. 副總的意見或你改過的地方告訴 Claude → 下次報告會更貼近副總習慣

## ⚠️ 資料存放提醒

這些檔案會存進 GitHub。如果 repo 是**公開**的，任何人都看得到內容，
所以真實的工作與會議資料**請放在私人（private）repo**。
