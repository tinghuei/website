# 副總交辦事項

資料檔：`work-assistant/data/副總交辦.md`（主檔）、`work-assistant/data/工作事項.md`

## A. 登錄新交辦

1. 讀 `副總交辦.md`，先確認是不是既有事項的追加指示 → 是就更新原事項的進度紀錄與注意事項，不開新號。
2. 新事項取最大編號 +1 建立 `VP-###`，**所有欄位都要填**：交辦日、來源、期限、副總原話、注意事項。
3. 分類：
   - ⚡ 即時完成：使用者表示已當場處理完，或屬於一次性、當天可完成的小事（回電、轉寄、確認一件事）
   - 📌 待辦：需要排時間做，有明確產出（報告、文件、安排、採購）
   - 👁 追蹤：需等別人回覆、跨週持續關注、或副總要求「定期回報」「盯著」的事
   - 判斷不出時問使用者
4. 待辦與追蹤類同時在 `工作事項.md` 建立 W 編號並互相標註來源。
5. 副總說的話若是**通則**（不只適用這件事），另外加到「副總常提醒的通則」。
6. 回覆：`已記錄 VP-### 〔分類〕，期限 MM/DD；副總特別提醒：…`

## B. 狀態更新與結案

- 完成 → 移到「已結案」，寫結案日與如何回報副總；**保留原話與注意事項**（之後同類工作要提醒）。
- 追蹤事項每次有新消息就在進度紀錄加一行日期＋內容。
- 期限已過未結案的，在標題加 `⏰逾期`。

## C. 查詢

使用者問「副總交辦還有哪些」：依 待辦→追蹤 列出，逾期與 3 天內到期的放最前面，每項一行（編號、事項、期限、狀態）。
使用者問「副總之前怎麼說 XX」：搜尋整份檔案（含已結案與通則）以及 `work-assistant/meetings/`，引用原話與日期。
