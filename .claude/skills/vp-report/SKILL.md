# 主管會議報告（副總視角）

資料檔：`work-assistant/data/工作事項.md`、`副總交辦.md`、`副總觀點.md`；輸出到 `work-assistant/reports/YYYY-Www-主管會議報告.md`

## A. 產出報告

1. 讀三個資料檔，以及 `work-assistant/reports/` 最近一份報告（延續格式、追蹤上週報過的事）。
2. 挑選上報項目：「可上報」⭐ 全部列入；△ 視篇幅放「其他」；副總交辦中「追蹤」類有新進度的一定要報。
3. **排序**：① 需要副總決策/協助的事 → ② 副總交辦事項進度 → ③ 重要成果 → ④ 下週計畫。
4. **每項寫法**（依副總觀點調整）：
   - 一句話結論在前（完成了什麼 / 卡在哪）
   - 數字與比較（有資料才寫，沒有就不寫，不可捏造）
   - 下一步：誰、做什麼、何時
   - 需要副總做的事明確寫出：「請副總裁示／協調…」
5. 上週報告中說「下週完成」的事，本週一定要交代結果，即使延誤也要說明原因與新期限。
6. 報告前用 `副總觀點.md` 第二節「副總常問的問題」逐項自我檢查，把預期會被問的答案準備在「備詢」區（不在主文）。

## 報告格式（副總觀點檔若有指定格式則以其為準）

```
# 主管會議報告｜YYYY/MM/DD（第 WW 週）｜報告人：

## 一、需請副總裁示/協助
1. 〔事項〕：結論。需要：…（期限 MM/DD）

## 二、副總交辦事項進度
| 編號 | 事項 | 狀態 | 本週進度 | 下一步/預計完成 |

## 三、本週重點成果
1. …

## 四、下週計畫
1. …

---
### 備詢（不印出，口頭準備用）
- 副總可能問：… → 回答：…
```

完成後回覆：上報項目清單、刻意不報的項目與理由、資料不足需補的數字。

## B. 學習副總觀點

使用者提供副總的批註、退件、改稿、會議中的評語時：
1. 判斷屬於哪一類：偏好（第一節）、常問問題（第二節）、退回修改（第三節）。
2. 寫入 `副總觀點.md` 對應區塊，附日期與出處，盡量保留副總原話。
3. 若新觀察與第四節「預設假設」或第五節「評估標準」衝突，以實際觀察為準並修改。
4. 若是對某件具體工作的提醒，也同步記到 `副總交辦.md`（事項的注意事項或通則）。
5. 回覆使用者：「學到了：…，之後寫報告會…」。
